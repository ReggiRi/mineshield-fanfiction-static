# Статистика фанфиков для Коалиции Майншилд

Одностраничный сайт для сбора статистики по выгрузке фанфиков за выбранный промежуток времени. Работает полностью в браузере, без сервера и сборки, поэтому подходит для GitHub Pages.

## Как пользоваться

1. Вставьте таблицу в поле «Вставьте таблицу» или загрузите файл `.csv` / `.tsv` / `.txt`.
   - Поддерживается выгрузка ficbook (CSV/TSV с колонками `visit-link`, `author`, `hidden-xs`, `ds-label`).
   - Поддерживается обычная таблица с заголовками: название, автор, направленность, рейтинг, статус, дата, слова, страницы, части.
2. Нажмите «Разобрать таблицу».
3. Укажите начало и конец промежутка (границы включительно) и нажмите «Обработать».
   - Работы **раньше начала** периода убираются сразу.
   - Работы **позже конца** периода показываются списком. По умолчанию они не учитываются; отметьте те, которые нужно оставить.
4. Статистика обновляется сразу при изменении галочек. Кнопка «Скопировать отчёт» копирует текстовый отчёт.

## Что считается

- число фанфиков и число уникальных авторов;
- авторы, написавшие больше одной работы, с числом работ;
- распределение по направленности (Слэш, Джен, Смешанная, Гет, Другие виды отношений, Фемслэш, Статья, Не определено);
- распределение по рейтингу (G, PG-13, R, NC-21, NC-17);
- число замороженных / завершённых / находящихся в процессе;
- завершённые работы в одну часть и в две и более частей;
- сумма слов и страниц завершённых работ. Работы без размера учитываются в числе работ, но не входят в сумму.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него файлы `index.html`, `styles.css`, `parser.js`, `app.js` (ветка `main`).
2. Откройте **Settings → Pages**.
3. В блоке **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`. Сохраните.
4. Через минуту сайт будет доступен по адресу `https://<username>.github.io/<repository>/`.

Реальную выгрузку с данными в репозиторий класть не нужно — она вставляется на сайте и обрабатывается локально в браузере.

## Локальный запуск

Достаточно открыть `index.html` в браузере. Если браузер ограничивает работу, запустите локальный сервер:

```bash
python3 -m http.server 8000
```

и откройте `http://localhost:8000/`.
